Security Policy

Last updated: April 24, 2026 · SaMD Risk Assessment

Overview

Cahill Consulting Group LLC takes security seriously. This page describes the technical controls in place for the SaMD Risk Assessment Jira app and how to report security concerns.

Data in transit

All data transmitted between the app and Anthropic's API is encrypted in transit via HTTPS. No issue content is transmitted over unencrypted channels.

API key storage

Your Anthropic API key is stored using Atlassian Forge's built-in secret storage. It is never logged, never exposed in plain text, and Cahill Consulting Group LLC does not have access to it.

Infrastructure security

The app runs entirely on Atlassian Forge, Atlassian's serverless cloud platform. All platform-level security controls — including network isolation, access controls, and infrastructure hardening — are managed by Atlassian.

Vulnerability response

We follow Atlassian's Marketplace Security Bug Fix Policy for remediation timelines.

  • Critical vulnerabilities are addressed within 10 days.
  • High severity vulnerabilities are addressed within 4 weeks.

Reporting a security issue

To report a security vulnerability or concern, email support@complaintrisk.com. We will acknowledge your report within 48 hours and keep you informed of our progress.
